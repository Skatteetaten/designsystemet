## Formål med komponenten

Tag brukes til å markere eller utheve informasjon i en liten, farget boks med kort tekst inni. Den gjør det enklere for brukeren å raskt oppfatte status, kategori eller annen nøkkelinfo.

## Når bruke komponenten

- Når du vil vise statuser, kategorier eller nøkkelord.
- Når noe må fremheves på en diskré, men tydelig måte.
- Når brukeren raskt skal kunne skille mellom ulike tilstander eller typer informasjon.

## Når ikke bruke komponenten

- Ikke bruk mange Tag‑elementer på samme side — det skaper støy og reduserer effekten.
- Ikke bruk Tag som lenke til andre sider.
- Ikke bruk Tag til handlinger — bruk i stedet **Button**.

## Hvorfor anbefalingene finnes?

- Trafikklysfarger (grønn/gul/rød) er semantisk reserverte for å gi brukeren konsistente statussignaler på tvers av løsninger. Å bruke dem uten semantisk hensikt undergraver denne konvensjonen.
- Farge alene er ikke tilstrekkelig informasjonsbærer fordi fargeblinde brukere ikke kan tolke statusen — tekst må alltid supplere fargen (WCAG 1.4.1).
- Vi begrenser antall tags per flate for å bevare signaleffekten — mange tags på samme side gjør det vanskelig å vite hva som er viktig.

## Varianter (og når bruke dem)

### Størrelser

- **Medium:** Standardvariant for de fleste bruksområder.
- **Liten:** Brukes ved behov for kompakt presentasjon.

Begge størrelser kan ha ikon (ikonet er pynt og skjules for skjermleser).

### Farger

Fargevalget skal være bevisst og konsistent:

#### Meningsbærende farger (trafikklysmodell)

- **Grønn:** Positiv status, suksess, godkjent.
- **Rød:** Negativ status, feil, advarsel.
- **Gul:** Nøytral informasjon eller pågående status.

Disse fargene forventes å kommunisere status selv uten tekst. Ikon kan forsterke tolkningen.

#### Ikke‑meningsbærende farger

- **Grå** eller **gul** (når gul brukes uten semantikk)

Brukes kun som visuell støtte, ikke som statusindikator.  
Alle tagger bør da ha samme farge for å unngå forvirring.

### Plassering og justering

- Plasser Tag nær informasjonen den markerer.
- Ikke bruk Tag som primært visuelt element — den skal være støtte, ikke struktur.
- Pass på at flere Tag‑elementer ikke konkurrerer mot hverandre.

### Interaksjon og tilstander

- Tag er statisk og ikke interaktiv.
- Ikon (når brukt) er dekorativt og har ingen interaksjon.
- Kan inngå i tabeller, kort, paneler eller lister som statusmarkør.

## Tekst og språkbruk

- Bruk korte og presise ord, helst ett til to ord.
- Teksten skal formidle status eller kategori uten behov for forklaring.
- Unngå tekniske betegnelser som brukeren ikke kjenner intuitivt.

## Tilgjengelighet (UU / WCAG)

- Unngå kombinasjonen **blå tekst på rød bakgrunn** — gir utilstrekkelig kontrast.
- Ikoner markeres som pynt og skjules for skjermleser.
- Tag‑teksten må alene beskrive innhold eller status.
- Sørg for at fargebruk ikke er eneste bærer av informasjon når fargen er meningsbærende.
