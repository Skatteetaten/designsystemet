## Formatter returner

- value - Formatert visningsverdi
- onChange - Endringshåndterer
- onKeyDown - Tastaturhåndterer
- rawValue - Uformatert verdi (bare siffer)
- numberValue - verdi som javascript number (hvis type er 'number' ellers undefined)
