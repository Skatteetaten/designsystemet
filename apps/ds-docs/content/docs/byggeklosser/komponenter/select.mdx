## Når bruke komponenten

- Når det finnes 5 eller flere alternativer.
- Når du trenger å flere valg på liten plass.
- Når valget skal presenteres kompakt og brukeren kun kan velge ett alternativ.

## Når ikke bruke komponenten

- Ikke bruk til navigasjon mellom sider eller seksjoner.
- Ikke bruk når brukeren skal velge flere alternativer (velg da [CheckboxGroup](/byggeklosser/komponenter/checkboxgroup) eller annen flervalgskomponent).
- Når det finnes få valg, er [RadioGroup](/byggeklosser/komponenter/radiogroup) ofte best fordi brukeren kan se alle alternativene samtidig. Select kan likevel brukes når det er begrenset plass.

## Hvorfor anbefalingene finnes?

- Native select brukes for å gi brukerne forutsigbar og tilgjengelig atferd — nettleserens innebygde select har god støtte for skjermlesere og tastatur på alle plattformer.
- Grensen på 7+ alternativer er den øvre terskelen for RadioGroup: færre valg er lettere å sammenligne visuelt, men mange valg gjør listen uoversiktlig i et åpent format.

## Varianter (og når bruke dem)

### Standard atferd

Select bruker nettleserens innebygde funksjonalitet.  
Det gir:

- Native visning som varierer mellom nettlesere
- Forutsigbar og tilgjengelig atferd for brukeren

### Plassering og justering

- Sorter alternativer i en logisk rekkefølge, f.eks. alfabetisk.
- Unngå lange setninger som alternativer — hold valgene korte og skannbare.

### Interaksjon og tilstander

- Listen åpner seg i nettleserens egen stil og funksjonalitet.
- Select kan utvides med grupperte alternativer (optgroup) dersom listen er lang.
- Brukeren får kun velge ett valg — ingen multiple‑valgstøtte i designsystemets bruksmønster.

## Tekst og språkbruk

- Ledetekst skal alltid brukes og plasseres over feltet.
- Ledeteksten bør være kort (helst én linje).
- Hvis Select er plassert inne i en tabell, kan ledeteksten skjules (men skal fortsatt eksistere semantisk).

## Tilgjengelighet (UU / WCAG)

- Select‑komponenten følger systemets native tilgjengelighetsmønster.
- Sørg for:
  - tydelig og konsistent ledetekst
  - logisk sortering
  - korte og forståelige alternativer
- Unngå deaktivert tilstand — det kan være vanskelig for brukere å forstå hvorfor feltet ikke kan brukes.
